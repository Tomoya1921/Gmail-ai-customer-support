# Gmail問い合わせ返信テストプログラム

Gmailの「AI返信テスト」ラベルが付いた未読メールを1件だけ取得し、OpenAI APIで返信案を作成して、元メールのスレッドにGmail下書きとして保存するローカル実行用のテストプログラムです。

自動送信は行いません。作成された返信は必ずGmailの下書きで確認してください。

## できること

- 「AI返信テスト」ラベル付き、かつ未読のメールを1件だけ処理
- 「AI処理済み」ラベルが付いたメールは除外
- HTMLメールからも本文を抽出
- OpenAI APIで200～400文字程度の丁寧な日本語返信案を生成
- 元メールのスレッドに返信下書きを作成
- 成功後に元メールへ「AI処理済み」ラベルを付与

## 事前準備

### 1. Google CloudでOAuthクライアントを用意する

1. Google Cloud Consoleでプロジェクトを作成または選択します。
2. Gmail APIを有効化します。
3. OAuth同意画面を設定します。
4. OAuthクライアントIDを作成します。
   - アプリケーションの種類は「デスクトップアプリ」を選びます。
5. ダウンロードしたJSONファイルを、このフォルダに `credentials.json` という名前で置きます。

### 2. Gmailラベルを作成する

Gmailで次のラベルを作成してください。

- `AI返信テスト`

`AI処理済み` ラベルは、初回実行時にプログラムがなければ作成します。

### 3. .envを作成する

`.env.example` を参考に、このフォルダに `.env` を作成してください。

```env
OPENAI_API_KEY=sk-your-api-key
OPENAI_MODEL=gpt-4.1-mini
```

## インストール

```bash
npm install
```

## 型チェック

```bash
npm run typecheck
```

## 実行

```bash
npm run dev
```

初回実行時はターミナルにGoogle認証URLが表示されます。そのURLをブラウザで開いて認証してください。認証後、このフォルダに `token.json` が保存され、次回以降は同じトークンを使います。

## 手作業で行う流れ

1. `credentials.json` をこのフォルダに置きます。
2. `.env` を作成し、`OPENAI_API_KEY` と `OPENAI_MODEL` を設定します。
3. Gmailで `AI返信テスト` ラベルを作成します。
4. テストしたい未読メールに `AI返信テスト` ラベルを付けます。
5. `npm run dev` を実行します。
6. ターミナル表示を確認します。
7. Gmailの下書きを開き、返信内容を確認・修正します。
8. 問題なければ手動で送信します。

## 注意事項

- このプログラムはメールを自動送信しません。
- エラーが発生した場合もメールの削除や送信は行いません。
- APIキー、`credentials.json`、`token.json` は `.gitignore` に含めています。
- 同じメールを二重処理しないため、成功後に `AI処理済み` ラベルを付けます。
